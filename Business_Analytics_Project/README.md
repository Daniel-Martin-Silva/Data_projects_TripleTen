# Business Analytics Project

## 📌 Project Overview
This project analyzes raw user activity logs from an e-commerce platform to evaluate customer conversion funnels, retention rates, cohort behavior, and purchase activity.

🔗 **Project Spreadsheet**: [View Business Analytics Project Workbook](https://docs.google.com/spreadsheets/d/1tCf24c_K1juWisTQm-Lf8va1846kXhQqO1tXadYFjas/edit?gid=38637670#gid=38637670)

---

## 📊 Key Analyses & Deliverables
* **Conversion Funnel**: Analyzes user progression from product views to shopping cart additions and completed purchases.
* **Retention Rates**: Measures returning user engagement across defined timeframes.
* **Cohort Analysis**: Groups users by initial purchase date to track user lifecycle drop-off and retention trends.
* **Purchase Activity**: Summarizes transaction metrics, sales volume, and user behavior patterns.

---

## 🛠️ Tools & Skills
* **Excel / Google Sheets**: Pivot tables, conversion formulas, cohort analysis tables, and chart visualizations.
* **Business Analytics**: Funnel analysis, retention rate calculation, e-commerce metrics, and behavioral analysis.
