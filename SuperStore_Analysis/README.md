# SuperStore Return Analysis

## 📌 Project Overview
This project analyzes sales and product return patterns from the SuperStore dataset to identify key drivers behind customer returns and help lower return rates.

🔗 **Live Interactive Dashboard**: [View on Tableau Public](https://public.tableau.com/app/profile/daniel.silva5139/viz/SuperStoreAnalysis_17826993789140/SuperstoreReturnAnalysisDashboardCEOOverview)

---

## 📊 Dashboards & Visualizations Included
* **CEO Overview Dashboard**: High-level summary of total sales, returns, and executive metrics.
* **Sales vs. Returns Scatterplot**: Analyzes correlation between high-volume sales items and return frequency.
* **Return Rate by Product Category & Region**: Identifies specific product categories and geographic regions with elevated return rates.
* **Return Rate by Customer & State**: Highlights high-frequency return customers and regional hotspots.
* **Seasonality Line Chart**: Tracks return rate variations over time across months and quarters.
